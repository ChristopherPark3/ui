Add `Button` and `buttonVariants`, built on Base UI's Button. Variants: default, destructive, outline, secondary, ghost, link; sizes: default, sm, lg, icon. Supports `loading` (spinner, `aria-busy`, stays focusable), `aria-invalid` error styling, `focusableWhenDisabled`, and a smooth width animation (Motion) when the content changes (`animateWidth`, on by default). Style links with `buttonVariants()` instead of rendering them through Button.
