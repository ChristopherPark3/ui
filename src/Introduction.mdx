# @ceepeetres/ui

Personal component library built on Tailwind v4 and Radix primitives.

## Use it in an app

```bash
pnpm add @ceepeetres/ui
```

```css
/* app/globals.css */
@import "tailwindcss";
@import "@ceepeetres/ui/styles.css";
```

```tsx
import { Button } from "@ceepeetres/ui";
```

## Theming

All colors are CSS variables (`--primary`, `--background`, …) defined in `styles.css`.
Override them in your app's `:root` / `.dark` to re-brand without touching the library.
Use the **Theme** toolbar button above to preview dark mode.
